# 少色拼豆图纸

> 状态：**占位文档**。本目录目前只有指令骨架，`scripts/` 下的生成脚本与 `assets/` 下的色卡数据尚未迁入。迁入完整实现前，本 skill 不会产出图纸。

目标：用尽量少的实际豆子颜色，还原输入图片的主体与识别细节。每格对应一颗豆子；透明空格不放豆。

## 输入与默认值

只要求用户提供 **图片 + 总板宽×高（孔数）**。已知信息不要重复询问。

| 参数 | 默认处理 |
| --- | --- |
| 尺寸 | 单位为孔/格；只给厘米时先询问孔数或实际孔距 |
| 色卡 | 迁入实现后使用 `assets/` 下的社区参考色卡，并注明色号来源，不能冒充其他品牌 |
| 颜色上限 | 默认最多 24 色，比较 1/2/4/6/8/12/16/24 色预算下的方案 |
| 构图 | 等比例完整放入板内，余白不放豆，不默认裁切主体 |

## 制作流程

1. 查看原图，确认孔数、主体、五官/文字等需保留的细节，以及有效颜色。
2. 调用 `scripts/` 下的生成脚本产出候选，避免在对话里重新实现量化与排版。
3. 对照原图、候选对比图与推荐预览做视觉复核；自动选择只是启发式，关键细节丢失时改选高一档候选或保护区域重跑。
4. 校验网格尺寸、色数上限、色号存在性、总豆数与分板拼接，再交付。

可选参数与色卡格式见 [references/options.md](references/options.md)。

## 交付物

- `preview.png`、`comparison.png`：像素效果与不同色数对比。
- `pattern.png` / `pattern.pdf`：逐格色号、行列坐标与十格线。
- `grid.csv`、`beads.csv`、`pattern.json`：每格色号、每色用量与权威网格数据。
- 指定单板尺寸时输出 `boards/` 分板图。

## 关键约束

- 所有图表与数量必须从同一份 `pattern.json` 派生，不手工改色号。
- 白色豆子计数，透明空格不计数；不自动删除散点或小色块（可能是眼睛、高光、文字）。
- 不把「颜色少」当作唯一质量指标：先保证主体可识别，再在视觉相近方案中选更少色。
- 色卡等第三方资源必须保留原许可文件，并在 `THIRD_PARTY_NOTICES.md` 登记；屏幕 RGB 不等于实物颜色。
- 指令中不写本机绝对路径，输出只写到用户工作目录。
