# 可选参数与色卡格式

> 占位文档：随生成脚本一起完善。此文件由 `SKILL.md` 按需加载，平时不进入上下文。

## 计划中的参数

| 参数 | 说明 | 默认 |
| --- | --- | --- |
| `--image` | 输入图片路径 | 必需 |
| `--width` / `--height` | 总板宽高，单位孔 | 必需 |
| `--max-colors` | 色数硬上限 | 24 |
| `--palette` | 色卡文件 | `assets/` 下的参考色卡 |
| `--output` | 输出目录，写用户工作目录 | 必需 |

## 色卡数据格式

迁入实现后在此说明 JSON 结构（色号、名称、RGB、来源与许可）。色卡必须附带原许可文件，并在根目录 `THIRD_PARTY_NOTICES.md` 登记来源链接；屏幕 RGB 仅供参考，不能承诺不同批次实物颜色一致。
