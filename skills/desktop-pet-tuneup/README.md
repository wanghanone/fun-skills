# 桌宠调优 · desktop-pet-tuneup

> 让已有的桌宠跑得更顺、动得更自然，同时不改变它的性格。

![效果示意](examples/before-after.png)

**当前状态：占位文档**。指令骨架与检查清单已就位，示例项目和前后对比图待补。

## 能做什么

- 定位卡顿、CPU/内存占用、重绘范围等性能问题。
- 精简动画帧与状态机、改善点击与拖拽反馈、压缩素材体积。
- 给出可复测的基线与优化前后对比，而不是泛泛的建议。

## 输入与产出

| 输入 | 产出 |
| --- | --- |
| 项目路径 + 技术栈 + 优化目标 | 改动说明、指标对比表、前后截图、剩余问题清单 |

## 依赖

- 依项目而定；需要能本地启动并采集基线（帧率 / CPU / 内存 / 截图）。
- 本仓库不内置第三方桌宠素材。

## 快速开始

在客户端里说：「帮我优化 `./my-pet` 这个桌宠，主要解决动画卡顿」，并附上项目路径与启动命令。

## 素材与许可

前后对比截图请使用自己生成或已获授权的画面；第三方立绘、音效、字体须在根目录 `THIRD_PARTY_NOTICES.md` 登记。
