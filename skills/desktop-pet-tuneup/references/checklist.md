# 排查清单与基线采集

> 占位文档：随示例项目一起完善。此文件由 `SKILL.md` 按需加载。

## 基线先记下来

- 启动命令、目标平台与最低系统版本。
- 帧率或动画间隔、CPU 与内存占用（同一场景、同一时长）。
- 一段录屏或一组截图，用于优化后对照。

## 排查项

- [ ] 主循环 / 定时器是否重复注册，空闲时是否仍在重绘。
- [ ] 每帧是否重复解码图片、重建对象或分配大数组。
- [ ] 重绘范围是否覆盖整个窗口，能否做脏矩形。
- [ ] 动画帧数与帧率是否匹配，状态切换是否漏帧或卡死。
- [ ] 点击、拖拽命中区域与反馈延迟是否一致。
- [ ] 素材分辨率是否远超显示尺寸，格式与体积是否合理。
- [ ] 是否有未释放的监听、定时器、缓存。

## 验收

每步改动后仍能启动；用与基线相同的场景复测，产出可对比的数值或画面。无法量化时如实说明，并给出手动验证步骤。
